DEPLOYMENT STATUS
=================

Current production setup is ready on Vercel.

Live domains:
- https://robinfrancis.in
- https://www.robinfrancis.in

Current stack:
- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS
- Sanity Studio bundled to public/cms
- Resend contact API
- Vercel production hosting

Required checks before deploy:
- npm run typecheck
- npm run build

Deploy command:
- vercel --prod --yes

Post-deploy checks:
- curl -I https://robinfrancis.in/
- curl -L https://robinfrancis.in/sitemap.xml
- verify CSP, HSTS, X-Frame-Options, nosniff
- verify home, projects, blog, gallery, card, and one blog post

Known non-blocking warnings:
- npm audit reports dependency warnings that should not be force-fixed without testing
- Sanity Studio may report local/runtime package version drift
- Browserslist data may need periodic refresh
